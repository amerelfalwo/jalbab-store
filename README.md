# 🕌 جلباب — متجر المنتجات الإسلامية

متجر إلكتروني عربي (RTL) متكامل لبيع النقاب والعبايات والطرح، مبني بـ Django.

---

## ✨ المميزات

- 🛍️ **3 تصنيفات**: نقاب، عبايات، طرح
- 🎨 **تصميم عصري** بألوان (Off White / Black / Dark Green / Gold)
- 📱 **Responsive** بالكامل (Desktop / Tablet / Mobile)
- 🌐 **عربي RTL** بالكامل
- 🖼️ **Hero ديناميكي** من Django Admin
- 🛒 **سلة Session-based** بدون تسجيل دخول
- 💳 **Checkout كامل** مع تحقق من المخزون
- 📦 **إدارة الطلبات** بحالات (جديد → قيد التجهيز → تم الشحن → تم التسليم → ملغي)
- 📞 **صفحة تواصل** تحفظ الرسائل في قاعدة البيانات
- 🔒 **آمن** ضد Race Conditions في المخزون

---

## 🛠️ التقنيات

- **Backend**: Python 3.11+ / Django 5.0.6
- **Frontend**: HTML5 + CSS3 + Vanilla JavaScript
- **Database**: SQLite (تطوير) / MySQL أو PostgreSQL (إنتاج)
- **Static**: WhiteNoise
- **Images**: Pillow
